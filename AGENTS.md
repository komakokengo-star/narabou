## UGC安全対策（App Store Guideline 1.2）
- 通報は public.reports、ブロックは public.blocks、アカウント停止は profiles.suspended_at。通報・ブロックUIは src/components/ReportBlock.tsx に集約し、依頼/案件詳細ページから使う。停止ユーザーの強制ログアウトは _authenticated/route.tsx の beforeLoad で行う。

## 広告計測（LINEヤフー広告）
- Yahoo!広告のコンバージョン送信は src/lib/yahoo-ads.ts 経由のみ。ytag.js は window.ytag を定義せず window.yjDataLayer キューを処理するだけなので、ytag() は push(arguments) 形式（要素は [config]）で積むこと。config を直接 push するとエラー 없이 黙って計測されない。

## Native app config (Capacitor)
- `ios/` and `android/` are gitignored and regenerated by `npm run ios:setup`, so manual Xcode/Android Studio edits vanish on any rebuild; keep iOS purpose strings in `scripts/ios-privacy.mjs` and the AppDelegate push patch (`FirebaseApp.configure()` plus the APNs `didRegister/didFailToRegister/didReceiveRemoteNotification` forwarders — without either, `@capacitor-firebase/messaging` getToken() never resolves) in `scripts/ios-firebase.mjs`, and the `aps-environment` entitlement for every App build configuration in `scripts/ios-entitlements.mjs` (Xcode may attach Push Notifications to Release only, which breaks Debug runs) — all run automatically via `ios:setup` and `ios:sync`. Apple's upload check (ITMS-90683) fails the build's plist when the linked Firebase SDK references location APIs.
- Native push uses only `@capacitor-firebase/messaging`; never add `@capacitor/push-notifications` alongside it, because the two plugins fight over APNs registration.
- Never return or `await` a Capacitor plugin proxy from an async function/promise (wrap it, e.g. `{ fm: plugin }`): the proxy answers `.then` with a native method call that never resolves, so the await hangs forever.
